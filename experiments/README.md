# Experiments

| ID | Question | Status |
|---|---|---|
| [E1](E1-no-tactile-baseline.md) | Can the hand grasp and transport a pipette-shaped body with no tactile feedback? | designed, not run |

## Order, and why

E1 comes first because it is the denominator. Nothing about tactile feedback is
measurable here until the no-tactile floor exists — and E1 may itself end the
line of inquiry, if our hand cannot do the mechanical task at all.

Candidates behind it, unscheduled and deliberately unwritten until E1 reports:

- **E2** — does adding a synthetic contact signal (not a real tactile sensor;
  a fingertip contact-force readout MuJoCo can already produce) change any E1
  gate? This is the nearest honest approximation of the source claim available
  on this host, and it must be labelled as an approximation everywhere it
  appears.
- **E3** — the source's actual mechanism, if and only if the paper turns up and
  names a sensor we can model.

E3 is blocked on `evidence/source.md`: no primary source, no reproduction.
